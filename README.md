# Security Strategy Radar

A monthly-updated strategic briefing on the cybersecurity landscape with 1-year and 3-year outlooks. EU/Germany focus.

Published via GitHub Pages: https://devko.github.io/security-strategy-radar/

- Sections 1–6 (landscape) and the prediction scorecard are refreshed monthly.
- The 3-year outlook is revised quarterly.
- Sources are primary wherever possible (BSI, ENISA, CISA, EUR-Lex, GTIG/Mandiant, CrowdStrike, Verizon DBIR, Chainalysis).
